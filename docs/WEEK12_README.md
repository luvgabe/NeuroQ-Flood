# NeuroQ-Flood — Week 12 Progress Report

## Live Adaptive Quantum-Classical Flood Forecasting

### 1. Overview

During Week 12, NeuroQ-Flood was extended from historical
forecast evaluation to a live adaptive forecasting prototype.

The system now retrieves recent USGS measurements, generates
60-minute discharge forecasts, stores predictions, verifies
completed forecasts, and supports adaptive learning based on
forecast errors.

The implementation maintains the existing historical
evaluation functionality.

---

### 2. Live USGS Data Integration

The system retrieves recent measurements from:

- USGS Station: 08074000
- Location: Buffalo Bayou, Houston, Texas
- Measurements: Gage height and discharge
- Forecast horizon: 60 minutes

Recent observations are used to construct the forecasting
dataset and generate predictions for the latest available
measurement.

The system rejects observations when their forecast target
time has already passed.

---

### 3. Forecasting Models

NeuroQ-Flood produces three forecasting outputs:

**Persistence Forecast**

Uses the current discharge as the prediction for the
future discharge.

**Classical Forecast**

Uses a regression model trained on historical discharge
measurements and environmental features.

**Quantum-Hybrid Forecast**

Combines classical features with quantum-derived features
generated by a locally simulated quantum circuit.

The quantum circuit uses parameterized rotations and
entangling operations.

Current quantum calculations use local statevector
simulation rather than physical quantum hardware.

---

### 4. Persistent Forecast Memory

A persistent memory system was implemented in:

`neuroq/live_memory.py`

The system stores:

- Pending forecasts
- Completed forecasts
- Forecast timestamps
- Predicted discharge values
- Actual discharge values when available
- Forecast errors
- Adaptive quantum weights
- Saved model information

Runtime state is stored locally in:

`data/live/live_state.json`

This directory is excluded from Git tracking.

---

### 5. Forecast Verification

When NeuroQ-Flood runs, it checks whether previously
saved forecasts can be compared with newly available
USGS observations.

Completed forecasts record:

- Actual discharge
- Prediction error
- Absolute prediction error
- Eligibility for adaptive learning

The system also prevents duplicate forecasts from being
stored for the same observation.

---

### 6. Adaptive Learning

Adaptive learning was integrated through:

`neuroq/live_learning.py`

The learning process:

1. Identifies eligible completed forecasts.
2. Reconstructs the saved forecasting model.
3. Evaluates predictions using candidate quantum weights.
4. Uses forecast errors to guide weight adjustments.
5. Saves updated weights in persistent memory.
6. Marks processed forecasts to prevent repeated learning.

Quantum weight updates are constrained to a defined range.

Synthetic tests demonstrated that adaptive weights can
change and remain consistent after saving and reloading
the system state.

Real-observation-driven adaptive weight updates have not
yet been demonstrated.

### 9. Current Limitations

The following limitations remain:

- Real-observation adaptive learning has not yet been
  demonstrated.
- Live forecasting currently runs when manually invoked.
- Quantum calculations use local simulation.
- The system has not been validated on physical quantum
  hardware.
- Additional real-world forecast evaluations are needed
  before drawing conclusions about predictive accuracy.
